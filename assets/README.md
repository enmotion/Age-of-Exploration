# 资产工作区

- `assets/source/`：原始模型、贴图及来源说明；不直接发布。
- `public/assets/`：处理后的 Web 运行时资产；通过相对路径加载。
- `src/assets/catalog.ts`：稳定 ID、名称、来源、版本与采用状态。
- `src/engine/babylon/proceduralAssets.ts`：初始化的程序化占位资产。

当前三项示例由项目代码构建，无下载素材、外部贴图或 CDN 依赖。程序化来源记录指向构建代码。它们用于工程验证，不代表最终美术方向。

后续外部资源须记录来源 URL、作者、许可证、署名要求和原始文件路径，再进入加工、预览与确认流程。默认坐标约定为 Babylon.js 左手系、Y 轴向上，长度按米设计；模型导入时统一原点、单位、方向。当前尚未实现 GLB 导入、压缩、缩略图生成或可视化资产审核，详见根目录计划。
